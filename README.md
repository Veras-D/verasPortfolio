# Vivi Veras Portfolio

A personal portfolio website showcasing my skills, projects, and experience as a Full-Stack Developer.

## 📋 Overview

This portfolio website is designed to highlight my skills and projects in software development. It features a clean, modern design with responsive layouts and interactive elements.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome for icons
- Custom fonts (Engravers' Gothic, Havelock Titling)

```

├── fonts
```

## 🚀 Features

- **Responsive Design**: Optimized for various screen sizes and devices
- **Portfolio Showcase**: Highlights my development projects
- **Skills Section**: Displays my technical skills and expertise
- **Contact Form**: Allows visitors to send me messages
- **About Me**: Provides information about my background and experience
- **Social Media Integration**: Links to my professional profiles

## 📱 Pages

1. **Home (index.html)**
   - Hero section with introduction
   - Skills overview
   - Call-to-action sections

2. **Projects (projects.html)**
   - Showcase of my development projects
   - Filtering options by technology/category
   - Project details and links

3. **About Me (about.html)**
   - Professional background
   - Education and certifications
   - Personal interests

4. **Contact (contact.html)**
   - Contact form
   - Direct contact information
   - Social media links

## 📥 Installation and Setup

1. Clone the repository:
   ```
   git clone https://github.com/Veras-D/verasPortfolio.git
   ```

2. Navigate to the project directory:
   ```
   cd verasPortfolio
   ```

3. Open `index.html` in your preferred browser to view the website locally.
