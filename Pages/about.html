About Me

I began my programming journey in 2020 during college, focusing on Python and Data Science. Over the years, I've delved into diverse technologies, full-stack frameworks, and scalable architectures, always striving to adapt and innovate.

In 2024, I shifted my focus to Full-stack development, working extensively with technologies like React, Node.js, TypeScript, Spring Boot, .NET, MongoDB, PostgreSQL, and cloud DevOps tools like Docker and AWS. Today, I also leverage AI-assisted software development as a core multiplier in my engineering workflow.

By combining modern AI tools with software engineering fundamentals, I achieve faster code delivery and rapid architectural exploration without sacrificing standards. Backed by strict typing, automated testing (Jest, Cypress), and CI/CD security gates, I ensure every solution remains clean, reliable, and production-ready.

Beyond building software from scratch, I offer specialized services for auditing AI-generated code and rescuing "vibe-coded" projects. Rapid AI prototyping is great for momentum, but often leaves behind subtle runtime bugs, security holes, architectural debt, and missing tests. Drawing on hands-on experience evaluating and benchmarking AI-generated code across multiple languages, I help teams and founders debug, stabilize, and refactor fragile prototypes into clean, secure, and production-ready systems.
